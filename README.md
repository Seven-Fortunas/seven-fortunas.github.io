# seven-fortunas.github.io

The page at [seven-fortunas.github.io](https://seven-fortunas.github.io/). It points visitors to [sevenfortunas.com](https://sevenfortunas.com/) and to where everything else lives: becoming a 7fchain miner, the network explorer, the papers, Discussions and our repositories.

It's a single self-contained `index.html` with no build step. GitHub Pages serves it from `main`, so a change is live a minute or two after it merges.
